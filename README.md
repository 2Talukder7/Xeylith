# Xeylith - AI Character Companion

Xeylith is an experimental AI companion project exploring conversational AI, character personality, and interactive web experiences.

🌐 Live Demo

Try Xeylith online: https://xeylith.onrender.com

## Current Project

The project includes a Flask-based web interface with a character-inspired design.

### Features

- Web-based chat interface
- Character personality and conversational responses
- Interactive emoji response controls
- Time and date-related responses
- Utility and conversion features

Feature availability depends on the current implementation and configuration.

## Technologies

- Python
- Flask
- HTML, CSS, and JavaScript

## Getting Started

### Requirements

- Python
- Dependencies listed in `XeylithWeb/requirements.txt`

### Run locally

1. Clone or download this repository.
2. Open PowerShell in the repository directory.
3. Install the dependencies:

   ```powershell
   cd XeylithWeb
   python -m pip install -r requirements.txt
   ```

4. Start the application:

   ```powershell
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.
